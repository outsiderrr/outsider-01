# 里程碑 2：3D 人偶与实验室 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：**用 Three.js 把里程碑 1 的动作模型画成"会动的线稿"风格 3D 人偶，并做出完整可用的实验室（击球、站位、视角、速度、时间轴、实时读数、三视图），同时建立全站共用的设计令牌（颜色、字体、主题切换）。

**架构：**`src/render3d/` 只依赖模型的 `Joints` / `Pose` 和主题调色板；`src/sections/lab/` 组装渲染器和控件；`src/styles/` 提供两套主题的令牌。一个 WebGL 画布，主视图和三视图小窗用剪裁区域在同一个渲染器里绘制。

**技术栈：**Three.js 0.186、Fontsource（思源黑体可变字重、IBM Plex Sans 可变字重、IBM Plex Mono、IBM Plex Sans Condensed），Vitest 测纯逻辑。

**写法说明：**可测的纯逻辑（坐标换算、相机角度、画质分档、主题解析、文案查找）给出完整代码并先写测试；视觉代码（材质、人偶造型、版式）给出接口、关键算法和验收标准，实现时以截图检查迭代——这类代码会在调视觉时反复改，预先写死意义不大。

**依据：**规格第 6、7.2、8、9 节。

```ts
export type ThemeChoice = 'system' | 'light' | 'dark';
export type Theme = 'light' | 'dark';
export function resolveTheme(choice: ThemeChoice, systemDark: boolean): Theme {
  return choice === 'system' ? (systemDark ? 'dark' : 'light') : choice;
}
export function nextChoice(c: ThemeChoice): ThemeChoice {
  return c === 'system' ? 'light' : c === 'light' ? 'dark' : 'system';
}
```

### Task 3：文案字典（实验室部分）

`src/i18n/index.ts`：

```ts
import { en } from './en';
import { zh } from './zh';
export type Lang = 'zh' | 'en';
export type Dict = typeof zh;
const DICTS: Record<Lang, Dict> = { zh, en };
export function t(lang: Lang, path: string): string {
  const v = path.split('.').reduce<unknown>((o, k) => (o && typeof o === 'object' ? (o as Record<string, unknown>)[k] : undefined), DICTS[lang]);

}
```

### Task 4：坐标换算

```ts
// src/render3d/space.ts
import * as THREE from 'three';
import type { Vec3 } from '../model/vec';

export const CM = 0.01;

/** 模型坐标（cm；x 右、y 朝网、z 上）→ Three 坐标（m；x 右、y 上、z 指向底线后方） */
export function toThree(v: Vec3, out = new THREE.Vector3()): THREE.Vector3 {
  return out.set(v[0] * CM, v[2] * CM, -v[1] * CM);
}

/** 方向向量（不缩放） */
export function dirToThree(v: Vec3, out = new THREE.Vector3()): THREE.Vector3 {
  return out.set(v[0], v[2], -v[1]);
}
```

测试 `tests/space.test.ts`：`toThree([100, 200, 50])` 等于 `(1, 0.5, -2)`；右手系保持（模型 x×y=z 对应 Three 里 `dirToThree(x)×dirToThree(y)=dirToThree(z)`）。提交。

### Task 5：相机角度计算与预设

`src/render3d/cameraRig.ts` 的纯函数部分（先写测试）：

```ts
export type ViewName = 'axo' | 'front' | 'side' | 'top';
export interface ViewSpec { azimuth: number; elevation: number; zoom: number }
/** 方位角：相机在模型坐标里的方位（0 在球网一侧，90 在球员右侧）；仰角 0 是平视，90 是正上方 */
export const VIEWS: Record<ViewName, ViewSpec> = {
  axo: { azimuth: 32, elevation: 16, zoom: 1 },
  front: { azimuth: 0, elevation: 3, zoom: 1 },
  side: { azimuth: 90, elevation: 3, zoom: 1 },
  top: { azimuth: 0, elevation: 89.5, zoom: 1 },
};
/** 相机相对目标点的单位方向（Three 坐标） */
export function viewDirection(azimuthDeg: number, elevationDeg: number): [number, number, number] {
  const a = (azimuthDeg * Math.PI) / 180;
  const e = (elevationDeg * Math.PI) / 180;
  const mx = Math.sin(a) * Math.cos(e);
  const my = Math.cos(a) * Math.cos(e);
  const mz = Math.sin(e);
  return [mx, mz, -my];
}
/** 两个方位角之间走最短的弧 */
export function lerpAngle(a: number, b: number, t: number): number {
  const d = ((((b - a) % 360) + 540) % 360) - 180;
  return a + d * t;
}
```

测试：`viewDirection(0, 0)` 指向 Three 的 −z（球网方向）；`viewDirection(90, 0)` 指向 +x；`viewDirection(0, 90)` 指向 +y；`lerpAngle(350, 10, 0.5)` 等于 360（即 0），不绕远路。

DOM/Three 部分：`CameraRig` 持有正交相机，`setView(name)` 以 0.7 秒 easeInOutCubic 过渡方位、仰角、缩放；`setFree(on)` 时挂上 OrbitControls；仰角大于 70° 时把相机 up 向量平滑转向球网方向（Three 的 −z），保证俯视时球网在画面上方。提交。

### Task 6：画质分档

```ts
// src/render3d/quality.ts
export type QualityTier = 'high' | 'medium' | 'low';
export interface DeviceInfo { mobile: boolean; dpr: number; cores: number }
export function initialTier(d: DeviceInfo): QualityTier {
  if (d.mobile) return d.cores >= 6 ? 'medium' : 'low';
  return d.cores >= 4 ? 'high' : 'medium';
}
export const TIER_SETTINGS: Record<QualityTier, { shadows: boolean; maxDpr: number; capSegments: number; radialSegments: number; hatching: boolean }> = {
  high: { shadows: true, maxDpr: 2, capSegments: 8, radialSegments: 18, hatching: true },
  medium: { shadows: false, maxDpr: 1.5, capSegments: 6, radialSegments: 14, hatching: true },
  low: { shadows: false, maxDpr: 1.25, capSegments: 4, radialSegments: 10, hatching: false },
};
/** 连续 3 秒平均帧率低于 45 就降一档；最低到 low */
export class FpsGovernor {
  private acc = 0;
  private frames = 0;
  constructor(private tier: QualityTier, private onChange: (t: QualityTier) => void) {}
  sample(dtMs: number): void {
    this.acc += dtMs;
    this.frames += 1;
    if (this.acc < 3000) return;
    const fps = (this.frames * 1000) / this.acc;
    this.acc = 0;
    this.frames = 0;
    if (fps < 45 && this.tier !== 'low') {
      this.tier = this.tier === 'high' ? 'medium' : 'low';
      this.onChange(this.tier);
    }
  }
  reset(): void { this.acc = 0; this.frames = 0; }
}
```

测试：`initialTier` 四种设备；喂 3 秒 30 帧/秒的帧间隔会降一档并回调一次；喂 60 帧/秒不降；已是 low 不再回调。提交。

### Task 7：调色板与材质

`palette.ts`：`readPalette()` 用 `getComputedStyle(document.documentElement)` 读规格 6.1 的令牌，返回 `THREE.Color` 集合；`onPaletteChange(cb)` 监听 `themechange`。

`materials.ts`：
- **填充材质**：`MeshToonMaterial` + 3 级渐变贴图（亮面纸白、过渡、暗面 `--fig-shade`），`onBeforeCompile` 在最终颜色处插入屏幕空间排线：亮度低于阈值处按 45° 斜线叠加墨色，线距 4 px、强度随暗度增加；`hatching` 关闭时不插入。支持阴影。
- **描边材质**：`ShaderMaterial`，`side: BackSide`，顶点沿视空间法线外推 `uWidth`（世界单位）；所有描边共享一个 `uWidth` uniform，按"目标像素宽 × 每像素世界长度"更新（正交相机：`(top-bottom)/zoom/视口高度`）。三视图小窗绘制前各自更新一次。
- 导出 `createOutline(mesh)`：给一个网格配一个共享几何体的描边网格。

**验收：**在 Task 9 的场景里截图，人偶轮廓线在桌面约 1.5 px、粗细均匀；暗面有细斜线；深色主题下自动换成蓝图配色。

### Task 8：人偶

`Mannequin`：

```ts

  update(j: Joints, p: Pose, bothArms: boolean): void;
```

造型（cm，换算到 m）：
- 胶囊肢体（圆柱段长 = 骨段长，端部半球自然包住关节）：上臂 r 4.2、前臂 3.6、大腿 6.2、小腿 4.8、颈 4.5；脚是从脚跟到脚尖的胶囊 r 4；手、肩、髋关节处补小球。
- **可扭转的躯干**：10 个截面环，从骨盆底到肩线。环心沿二次贝塞尔曲线（骨盆竖直向上、到胸口时与躯干朝上方向相切）；环的"右"方向从骨盆右向量渐变到躯干右向量（腰部以上才开始扭）。截面半宽 / 半厚：髋 16×11、腰 13.5×9.5、胸 17×11、肩线 16×9，超椭圆指数 2.5（偏方，更像人台）。每帧更新顶点并重算法线；底部几环用髋的发力色、其余用躯干发力色（顶点色）。
- 头：半径 10 的球；**帽檐**：头前方偏上的扁半圆片，指向头的朝向，墨色——既有辨识度，又让人一眼看出视线方向。
- 关节标记：肩、肘、腕、髋、膝、踝 12 个点，固定 7 px 的墨色小圆环（Sprite，不随距离缩放）。
- 发力与刹车：每段材质颜色在纸白与 `--signal` / `--brake` 之间插值（双手反手时两条手臂都着色）。

**验收**（截图）：半开放正手引拍时，躯干可见明显扭转；四个视角下人偶比例协调、没有穿插破面；关节标记清晰不抢戏。

### Task 9：球拍、网球、扫掠带、注释、标签、舞台

- `racket.ts`：在局部坐标建一次（Y 沿拍杆、X 沿拍面宽度、Z 沿拍面法线，原点在右手），每帧用 `makeBasis(width, dir, normal)` 摆放。拍框是椭圆管、拍颈两根细管、拍柄圆柱、拍线 16×19 根细线段裁在椭圆内。发力时拍框染橙。
- `ball.ts`：黄绿色球 + 墨线描边；只在击球前后 0.1 秒出现（与原型的来球、出球规则一致）。
- `trail.ts`：拍头扫掠带——取 `[t-0.25, t]` 区间内 24 个时刻的"拍头顶点"和"拍颈点"连成带状网格，越早越透明，颜色 `--signal`；它直接按模型重新采样，所以拖动时间轴也一致。另画整条挥拍路线（引拍结束到随挥结束）的虚线。
- `annotations.ts`：地面上的肩线（墨色）、髋线（辅助色）投影，两者夹角弧和刻度；两脚之间的重心条和标记点。
- `labels.ts`：`setLabel(id, worldPos, html)` 每帧把 3D 点投影到屏幕并移动 HTML 标签；用于肩髋差度数、击球瞬间的拍速。
- `stage.ts`：`createStage(container, opts)` 返回 `{ setState(stroke, stance, t), setView, setFree, setAnnotations, setMultiView, render, dispose }`；按需渲染（只有时间、视角、尺寸或主题变化时才画）；地面是着色器网格（10 cm 细线、50 cm 粗线、离人越远越淡）加底线和中点标记；高画质用实时软阴影，其余用接触阴影贴图；三视图用同一个渲染器的剪裁区域画在主视图右侧。

**验收**（截图，桌面 1440×900 与手机 390×844，浅色与深色）：拍框、拍线清晰；扫掠带能看出挥拍平面且不遮住人；三视图三个小窗内容正确（正视看到胸口、侧视看到侧面、俯视看到肩线髋线）；控制台无报错。
